# Pinned deliberately. GPTCache's ONNX evaluator is the only part of it worth comparing against, and it
# is the part that stopped working with current libraries — so every version here is a version the
# measurement was actually taken with, not a lower bound.
#
# gptcache 0.1.44 declares onnxruntime==1.14.1, which has no wheel for any Python newer than 3.10. It is
# not a real constraint: 1.15.1 runs the model unchanged. numpy stays on 1.x because onnxruntime 1.15
# predates the 2.x ABI.
#
# transformers is current, and getting there took six lines rather than a version pin. GPTCache's
# evaluator calls `tokenizer.encode_plus`, which transformers 5 removed; compare.py forwards it to the
# documented replacement. The alternative was pinning back to 4.57.6, which carries two high-severity
# advisories with no fix below 5 and would have meant allowing them in CI for the sake of a method name.
gptcache==0.1.44
onnxruntime==1.15.1
transformers==5.5.0
numpy==1.26.4
