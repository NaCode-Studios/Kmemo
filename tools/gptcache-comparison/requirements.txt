# Pinned deliberately. GPTCache's ONNX evaluator is the only part of it worth comparing against, and
# it is the part that stopped working with current libraries — so every version here is a version the
# measurement was actually taken with, not a lower bound.
#
# gptcache 0.1.44 declares onnxruntime==1.14.1, which has no wheel for any Python newer than 3.10. It
# is not the binding constraint: 1.15.1 runs the model unchanged. The real constraint is transformers,
# because OnnxModelEvaluation.inference calls AlbertTokenizer.encode_plus, which modern transformers
# no longer has. 4.36.2 still does.
#
# huggingface_hub is pinned because transformers 4.36 imports helpers that later versions removed, and
# numpy because onnxruntime 1.15 predates the 2.x ABI.
gptcache==0.1.44
onnxruntime==1.15.1
transformers==4.36.2
huggingface_hub==0.20.3
numpy==1.26.4
